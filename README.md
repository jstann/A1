# Assignment 1: Webpage Creation in HTML

## Overview

For this assignment, I created a simple two-page personal website using HTML. The website consists of a homepage (`index.html`) and an introduction page (`introduction.html`). I also created an `img` folder to organize the images used for the website.

## What I Learned

I learned how to create a basic website using HTML, including multiple webpages, images, links, lists, and tables. I also learned how to organize files into folders and use relative file paths to connect everything together.

## Skills Practiced

* Creating HTML documents
* Using HTML headings and paragraphs
* Creating ordered and unordered lists
* Adding and formatting images
* Creating hyperlinks between webpages
* Creating HTML tables
* Organizing files and folders
* Using relative file paths
* Testing webpages in a browser
* Writing comments in HTML
